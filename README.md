This repository only contains the **redundancy resolution** of hybrid **Gough-Stewart robots**. This project was implemented partially in a Bachelor's Thesis and was modified in the graduate course _Optimal Design_, lectured by _Dr. Saeed Khodaygan_ at the _Mechanical Engineering Department_ of _Sharif University of Technology_. It resulted in a publication submitted to the _Iranian Conference of Biomedical Engineering (ICBME 2026)_.
